#### How I build with AI
- **Specs before code**: agents work from a written spec, not from a vague prompt.
- **`AGENTS.md` as the operating manual**: rules, context and boundaries for every project.
- **Reusable skills and rules** for coding agents (Claude Code, Codex, Cursor) and MCP integrations.
- **Clean architecture by feature**, so agents change one piece without breaking the rest.
- **Human review**: every AI-generated change is reviewed before it reaches production.
